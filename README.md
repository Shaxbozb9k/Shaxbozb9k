# Универсальный справочник (C++)

Небольшая учебная программа для первого курса: простая база данных с интерфейсом в консоли, поиском и возможностью добавлять записи.

## Возможности
- Консольный интерфейс (меню).
- Добавление записей.
- Просмотр всех записей.
- Поиск по ключевому слову.
- Хранение данных в файле `data/database.txt`.

## Сборка и запуск
```bash
g++ -std=c++17 -O2 -Wall -Wextra -o app src/main.cpp
./app
```

## Как пользоваться
1. Запустите программу и выберите пункт меню.
2. Добавьте запись (название, категория, краткое описание).
3. Используйте поиск по ключевому слову.

Данные сохраняются в `data/database.txt`, так что при следующем запуске база будет восстановлена.
